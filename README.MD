# 🚀 LostSchedule (로스트스케줄)

**"로스트아크 숙제, 이제 게임 밖에서도 간편하게 관리하세요."**

> 로스트아크 캐릭터 조회 및 레이드 체크리스트 기능을 제공하는 PWA 기반의 웹/모바일 앱입니다.

---

## 🌟 주요 기능 (Key Features)

### 🔍 캐릭터 실시간 조회

- 로스트아크 API를 통해 캐릭터의 장비, 각인, 능력치를 실시간으로 확인합니다.

### ✅ 레이드 체크리스트

- 캐릭터별 주간/일일 숙제 완료 여부를 기록합니다. 게임에 접속하지 않아도 폰으로 즉시 확인 가능합니다.

### 📱 PWA 지원

- 브라우저에서 '홈 화면에 추가'를 통해 앱처럼 설치하여 사용할 수 있습니다.

### 🤖 Android APK 제공

- 모바일 환경 최적화를 위해 안드로이드 전용 APK 설치를 지원합니다.

### 💾 데이터 로컬 저장

- `AsyncStorage`를 사용하여 별도의 로그인 없이도 사용자의 캐릭터 리스트와 체크 상태를 안전하게 저장합니다.
